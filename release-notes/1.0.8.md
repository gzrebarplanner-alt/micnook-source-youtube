MicNook 的 YouTube 匯入來源擴充（protocol 1）。

安裝：下載下面的 micnook-source-youtube-1.0.8.zip，在 MicNook 的「設定 → 匯入來源 → 安裝來源…」選這個檔，或直接把 zip 拖進 App。

## 1.0.8

- 修正：Windows 11 開著「智慧型應用程式控制」時，這個來源被系統擋下、無法匯入。現在來源程式有數位簽章；Windows 改用 python.org 官方（有簽章）的 Python 執行 yt-dlp，不再下載沒有簽章的 yt-dlp.exe
- 還是被系統擋下時，錯誤會說清楚是 Windows 的安全設定擋的

## 1.0.7

- YouTube 要求確認「不是機器人」時，改說是 YouTube 暫時擋了這個網路、請稍後再試或換網路（以前被說成影片有觀看限制）

## 1.0.5

- 修正：MicNook 的資料位置含中文（例如使用者名稱是中文）時，下載音訊與影片一律失敗，還被說成「連不上 YouTube」

---

- 支援 Windows 與 Mac（Apple 晶片）
- 裝好後就在背景從 GitHub（yt-dlp/yt-dlp）下載 yt-dlp（Windows 另外從 python.org 下載 Python，共約 20 MB；Mac 約 25～40 MB），之後每 3 天自動更新
- 沒有 MicNook 的官方簽章，安裝時會顯示「未簽章」
- 使用前請先閱讀 TERMS.md：只能用來存取你有權使用的內容
